この川は、今日 酸素と炭素を
どちらに動かしたか

東京都多摩市を流れる大栗川の同じ浅い区間で、朝・昼・夕（日没後を含む）に水質と光を記録しています。測った値を並べるだけでなく、そこから酸素の正味生産量・大気との交換量・二酸化炭素の放出量を誤差つきで計算し、その日の川が有機物をつくる側にいたか、分解する側にいたかを毎日判定しています。

Latest monthly report · 2026年7月

川底の光合成が月を通じて強まり、2回の出水がそれを2度リセットした

2026年7月、東京都多摩市の大栗川の同じ浅い区間で28日・73件の観測を行いました。日中に川がつくる酸素の量は月の前半から後半にかけて大きく増え、同じ明るさの日どうしを比べても後半ほど多くの酸素をつくるようになりました。一方で7月18日と7月26〜27日の出水はその能力を2度リセットし、1回目は約5日で戻ったのに対し、2回目は月末まで完全には戻りませんでした。

  • 日中の酸素飽和度の上がり幅は月中央値 +34.4 ポイント、最大 +56.0 ポイント（7/25）。午後の最高値は飽和度 141.8%（7/15）に達した。
  • 光の量で割った「同じ光あたりの酸素生産」が月を通じて上昇（ρ = +0.77, p < 0.001, n = 24）。天気が良くなったからではなく、川底そのものが変わった。
  • 朝の酸素飽和度と pH はむしろ低下（それぞれ ρ = −0.69, ρ = −0.71）。昼につくる量だけでなく、夜に使う量も増えている。
  • 7/18 の 37.75 mm の雨で藻類スコアが 3 → 1、裸石スコアが 0 → 1 に変化し、日中酸素生産は約 3 割減。約 5 日で回復した。

About

この観測について

石を採取せず、川の中に機材を置きっぱなしにせず、同じ場所・同じ時刻・同じ手順で繰り返すことを最優先にした観測です。1回ごとの精度より、続けることで見えるものを重視しています。

朝と午後の差を見る

朝は夜のあいだに酸素を使い切った状態、午後は日中の光合成のあとの状態です。この2回の差が、その日に川がどれだけ働いたかの目安になります。

川底に届く光を測る

水面上と川底の光量を測り、気象台の日照時間から推定した日射量と組み合わせます。応答が弱い日に、原因が光不足なのか川底側なのかを分けるためです。

雨のあとを追いかける

増水は川底の付着膜を洗い流します。剥がれてから戻るまでを毎日記録することで、川がどれくらいの速さで回復するのかが見えてきます。

この観測は正式な GPP / ER 推定や、付着藻類の生物量測定を置き換えるものではありません。日常的に続けられる形で変化を検出し、詳しく調べるべき時期を絞り込むためのスクリーニングとして設計しています。詳しい限界は各月報の「言えないこと」に記載しています。
