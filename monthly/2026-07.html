Monthly report 2026-07

川底の光合成が月を通じて強まり、2回の出水がそれを2度リセットした

2026年7月、東京都多摩市の大栗川の同じ浅い区間で28日・73件の観測を行いました。日中に川がつくる酸素の量は月の前半から後半にかけて大きく増え、同じ明るさの日どうしを比べても後半ほど多くの酸素をつくるようになりました。一方で7月18日と7月26〜27日の出水はその能力を2度リセットし、1回目は約5日で戻ったのに対し、2回目は月末まで完全には戻りませんでした。

公開 2026-08-02　/　対象期間 2026年7月　/　観測地点 大栗川（東京都多摩市）

要点

  • 日中の酸素飽和度の上がり幅は月中央値 +34.4 ポイント、最大 +56.0 ポイント（7/25）。午後の最高値は飽和度 141.8%（7/15）に達した。
  • 光の量で割った「同じ光あたりの酸素生産」が月を通じて上昇（ρ = +0.77, p < 0.001, n = 24）。天気が良くなったからではなく、川底そのものが変わった。
  • 朝の酸素飽和度と pH はむしろ低下（それぞれ ρ = −0.69, ρ = −0.71）。昼につくる量だけでなく、夜に使う量も増えている。
  • 7/18 の 37.75 mm の雨で藻類スコアが 3 → 1、裸石スコアが 0 → 1 に変化し、日中酸素生産は約 3 割減。約 5 日で回復した。
  • 7/26〜27 の連続降雨（14.5 mm・21.0 mm）による2回目のリセットからの戻りは鈍く、月末時点で出水前の約 75% にとどまった。
  • 日没後の直接測定から、初めて誤差つきの総一次生産（GPP）を算出：1.12 ± 0.07 mg O2/L/h（7/31）。

1. 今月の観測

観測は大栗川の同じ浅い区間で、原則として朝（7時前後）と午後（13時前後）の2回、pH・溶存酸素・電気伝導度・水温・光量（PAR）・川底写真を記録する方式です。石を採取せず、川の中に機材を据え置かず、同じ立ち位置・同じ画角で繰り返すことを優先しています。

7月は28日にわたって73件の公開対象記録が得られました。内訳は朝27件、午後24件、それ以外の時間帯（早朝・夕方・日没後など）が22件です。朝と午後がそろって日中変化を計算できたのは24日でした。7月17日は増水で観測地点に近づけず、7月26日は増水により危険と判断して午後の測定を中止しています。この2日は「欠測」ではなく「安全上の中止」として記録しました。

気象条件はアメダス府中・八王子の平均値を用いています。7月の日照時間合計は 142.65 時間（日平均 5.09 時間）、各日07:00時点の直近24時間雨量の合計は 116.5 mm、1 mm 以上の降雨があったのは9日でした。

3. 主な結果

3.1 日中に川がつくる酸素の量が、月を通じて大きく増えた

朝から午後にかけての溶存酸素飽和度の上がり幅は、7月上旬には +4〜+11 ポイント程度でしたが、月末には +38〜+40 ポイント前後で推移しました。日付との順位相関は ρ = +0.64（p = 0.0007, n = 24）です。pH の日中上昇も同じ動きを示し、両者は強く連動しました（ρ = +0.82, p < 0.001）。pH の上昇は光合成による二酸化炭素の消費を反映するため、酸素の増加が物理的な撹拌ではなく生物由来であることを支持します。

この変化は連続的ではなく、7月8日から9日にかけて段階的に立ち上がりました。日中上昇は +15.9 から +27.3 ポイントへ跳ね、同じ日に現地の目視による藻類スコアも 1 から 3 へ変化しています。川底の付着膜（バイオフィルム）が観察可能な量まで発達した時期に対応すると考えられます。

3.2 「晴れた日が多かったから」では説明できない

日中の酸素生産はその日の光の量にも当然左右されます。推定川底PAR日積算との相関は ρ = +0.51（p = 0.010）でした。そこで、酸素の増え幅を川底に届いた光の量で割った「同じ光あたりの生産量」を求めたところ、この指標自体が月を通じて明確に上昇していました（ρ = +0.77, p < 0.001, n = 24）。同じだけ明るい日を比べても、後半の日ほど多くの酸素をつくっています。

日付と川底PARを同時に説明変数とした重回帰では、モデル全体の決定係数は R² = 0.70 でした。日付（＝付着膜の蓄積過程）を除くと R² は 0.28 に落ち（寄与 ΔR² = 0.42）、川底PARを除いた場合の低下は ΔR² = 0.22 にとどまります。7月の日中酸素生産を動かした主因は天候ではなく、川底側の状態変化だったと読めます。

川底光到達率（水面上PARに対する川底PARの比）は月平均 0.52、標準偏差 0.04 と安定していました。水の濁りによる遮光の月内変化は小さく、この点でも「光環境の変化が主因」という説明は支持されません。

3.3 朝の酸素とpHは、逆に下がっていった

昼の生産が増える一方で、朝の状態は反対方向に動きました。朝の溶存酸素飽和度は月前半5日平均の 87.9% から月末5日平均の 80.0% へ低下し（ρ = −0.69, p < 0.001, n = 27）、朝の pH も同様に低下しています（ρ = −0.71, p < 0.001）。最低は7月27日の 75.2% でした。

昼につくる酸素が増えているのに朝の酸素が減るのは、夜間に消費される酸素も同時に増えているためと解釈できます。付着膜と底質の呼吸量が増えたこと、および水温が月を通じて上昇したこと（朝の水温は 21.0 ℃ から 24.5 ℃ へ）の両方が寄与していると考えられます。生産と呼吸がともに大きくなり、川の一日の中での酸素の振れ幅そのものが拡大した月でした。

3.4 2回の出水が、能力を2度リセットした

7月18日、07:00時点の直近24時間雨量は 37.75 mm を記録しました。この前後で、現地の目視による藻類スコアは 3 から 1 へ、裸石スコアは 0 から 1 へ変化しています。日中の酸素上昇は直前3日（7/14–16）の平均 +43.8 ポイントから 7/18 には +30.2 ポイントへ、7/21 には +26.5 ポイントまで落ちました。付着膜が物理的に剥離した「洗い流し型」の攪乱として整理しています。

その後の回復は速く、7/22 に +44.1、7/23 に +47.0 ポイントと出水前の水準を回復し、7/25 には月間最大の +56.0 ポイントに達しました。剥離から約5日で元の水準に戻った計算になります。

2回目は7月26日（14.5 mm）と27日（21.0 mm）の連続降雨です。26日は増水のため午後の測定を中止しました。直前3日（7/23–25）の平均 +51.8 ポイントに対し、7/27 は +33.2、7/28 は +30.4 ポイントまで低下しています。ここからの戻りは1回目より鈍く、7/30 が +40.0、7/31 が +38.1 ポイント（2日平均 +39.1）で、出水前の約 75% の水準にとどまったまま7月を終えました。

2回のリセットで回復速度が違った理由は、今回のデータでは断定できません。連続する2回の攪乱が短い間隔で起きたこと、2回目の後の日照条件が相対的に不良だったこと（7/27 の日照は 0.5 時間）などが候補として挙がりますが、攪乱イベントの数がまだ少なく、いずれも仮説の段階です。

3.5 日没後の測定で、初めて誤差つきの光合成量を出せた

7月後半に、日没後の時間帯を含む測定を追加しました。光合成が完全に止まった状態での酸素の減り方は、その区間の呼吸速度を直接与えます。7月30日と31日の日没直後の測定から、呼吸速度は 0.672 ± 0.070 mg O2/L/h と求まりました。

この呼吸速度を朝の正味生産（7/31 の 07:14–13:05 で 0.448 mg O2/L/h）に足し戻すことで、総一次生産（GPP）を 1.12 ± 0.07 mg O2/L/h と推定しました。これは本プロジェクトで初めて誤差の範囲を明示できた光合成量の推定値です。

あわせて、日没直後（19–21時）と深夜（21時–翌04:30）で呼吸速度が大きく異なることが見えました。日没直後は 0.67 前後であるのに対し、深夜は 0.30 前後と半分以下です。夜通し一定の呼吸速度を仮定する標準的な河川代謝推定は、この区間では夜間の呼吸を過大評価する可能性があります。

なお、これらの推定に必要な再曝気係数 k は午後の回帰から 0.1345 ± 0.0249 /h（r = 0.924, n = 7）と求めています。k を 0.05〜0.25 /h の範囲で振った感度解析では GPP は 0.95〜1.34 mg O2/L/h の間に収まり、上記の結論の向きは変わりません。

3.6 「白波が立つと酸素が入る」という予想は、支持されなかった

水面の白波が強い日ほど大気からの酸素の取り込み（再曝気）が大きいのではないか、という仮説を、動画から算出した白波指標を使って検証しました。結果は、朝の正味生産との相関が ρ = +0.24（p = 0.48, n = 11）、流速指標との相関が ρ = −0.45（p = 0.17）で、いずれも統計的に有意ではありませんでした。

この区間の水深と流れの範囲では、白波の見た目の変化は再曝気の大きさを説明しないという結果です。動画指標そのものの検証も行い、川岸の植生が写り込む固定範囲での算出には交絡があること、範囲に依存しない流速指標のほうが目視評価とよく一致すること（ρ = 0.81, n = 12）を確認しました。8月以降は流速指標を主指標として継続します。

5. 方法と、この月報で言えないこと

この月報が根拠にしていること

  • 同一地点・同一手順・固定時刻の反復観測（28日・73記録）。
  • 朝と午後の差を日中光応答の proxy として用い、pH と溶存酸素の両方が同方向に動くことを条件に生物起源と判断している。
  • 光の交絡は、アメダス日照時間から推定した全天日射量と、現地測定の川底光到達率を組み合わせた推定川底PAR日積算で統制している。
  • 日没後の直接測定による呼吸速度は、光合成がゼロという物理的条件に依拠しており、モデル仮定が少ない。

この月報では言えないこと

  • 付着藻類のクロロフィルa量、有機物量、種組成は測定していない。「藻類が増えた」は目視スコアと写真、および代謝応答からの推定である。
  • 報告した GPP・呼吸速度は特定日の値であり、月全体の代謝収支ではない。再曝気係数 k の不確かさも残る。
  • 攪乱イベントは2回のみで、回復速度の違いの原因は特定できていない。
  • 栄養塩濃度を測定していないため、生産量の増加が栄養塩条件と関係するかは判断できない。
  • 川底写真は水が澄んだ日にしか撮れないため、濁った日が構造的に除外される選択バイアスがある。

6. 8月に向けて

7月の結果を受けて、8月は次の3点を重点的に進めます。第一に、日没後測定の反復です。呼吸速度の推定は現在2晩分しかなく、前半夜と後半夜の差を確定するには晩数が要ります。第二に、3回目以降の攪乱イベントの記録です。回復速度を左右する条件を切り分けるには、攪乱の反復が不可欠です。第三に、午後の日陰入り時刻が季節とともに早まるため（7月末で16:29、8月末には16:00）、午後測定と夕方測定の時刻設計を日陰入りに合わせて調整します。
